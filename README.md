# newtrn/tap

Homebrew casks by [newtrn](https://github.com/newtrn).

```sh
brew install --cask newtrn/tap/pip
```

| Cask | What it is |
|---|---|
| [`pip`](https://github.com/newtrn/pip) | A slime in your Mac's menu bar that watches your Claude Code, Codex and AI API usage |

Casks are updated automatically when a new release is published.
